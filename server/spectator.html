GETTING STARTED
邀请玩家
让玩家打开客户端，输入上方的连接地址。
同一台电脑可以使用 ws://localhost:8765。其他设备需要使用这台服务器的局域网或公网地址，以及服务器的游戏端口。
服主入门与世界规则
先启动服务端，把上方游戏地址发给玩家。控制台只观察正在运行的世界；修改“准备下一个世界”后需要生成命令并重启。server.properties 与命令行参数共同配置端口、速度和世界；命令行覆盖配置文件。
均衡、丰饶和挑战提供不同资源条件；深潜世界采用有限感知和隐藏地图。移动、繁殖、进食等代价由服务端裁决，玩家的规则只提交动作。高级服主可使用 --world-rules 指向可信 Python 文件；on_epoch 返回允许的参数更新，on_event 可提出有限世界事件。完整接口见 docs/world_rules_zh.md 和 docs/WORLD_MANIFEST_zh.md。
服务器设置与启动方式
当前页面用于观察正在运行的世界。启动参数和世界规则需要在服务器启动时配置。
server\start.bat --port 8765 --tick-ms 3000
高级服主可以使用 --world-rules 选择自己的规则文件。
