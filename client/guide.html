五分钟写出第一个物种

打开客户端的“进阶模式”，将下面的代码放入编辑器。点击“预览代码”，满意后点击“启用代码”。不需要导入 NumPy，也不需要手动处理数组。

def decide_cell(cell):
    if cell.food_here > 0 and cell.energy < 20:
        return cell.eat()

    empty = cell.empty_neighbors()
    if empty and cell.energy >= 13:
        return cell.reproduce(empty[0])

    if empty and cell.energy > 4:
        return cell.move(empty[0])

    return cell.wait()

每个时刻，游戏对你的每个细胞调用一次这个函数。每个细胞返回至多一个动作；服务器根据能量、距离和目标位置判断动作能否成功。

细胞能看见什么？

信息含义
cell.energy细胞的能量
cell.food_here当前位置的食物
cell.x、cell.y、cell.tick坐标和当前时刻
cell.state、cell.cell_type公开整数状态和类型
cell.empty_neighbors()空邻格的方向列表，如 (1, 0)
cell.surrounding()八个邻格；可读取 is_enemy、is_empty、food、energy 等

返回一个动作

cell.eat() 进食；cell.move((dx, dy)) 移动；cell.reproduce((dx, dy)) 繁殖；cell.attack((dx, dy)) 攻击；cell.change_type(1) 切换装甲；cell.wait() 等待。

让细胞记住一个状态

def decide_cell(cell):
    return cell.set_state(1 - cell.state)

这个例子让状态在 0 和 1 之间切换。状态是公开整数，移动时保留，新生细胞从 0 开始。修改状态占用该细胞本时刻的动作。

连接和协作

在进阶示例中选择“连接与分享示例”。cell.reproduce(direction, bond=True) 让新生细胞与父细胞相连；cell.bond(direction) 与邻居连接；cell.unbond(direction) 断开；cell.transfer(direction, 3) 向已连接邻居传递最多 3 点能量。n.is_bonded 判断是否连接。每次操作占一个动作。普通移动无法移动连接中的细胞；cell.move_group(direction) 可以尝试让连接组一起移动，所有目标都要可用、每个细胞都要有足够能量，最多 256 个细胞。

需要新版服务端。“自己人”是同一玩家的细胞，不一定是同一个独立生物；地图边界只是空间提示，不保证马尔可夫毯。

观察生命世界

地图中的细胞会缓慢呼吸，相连的细胞会共享节奏。使用地图工具栏“动态 开/关”控制呼吸和事件动画；客户端默认开启，也可以随时关闭。“定位我的细胞”会定位到视野附近的一个己方细胞并放大地图。呼吸只是视觉效果，不影响模拟与游戏规则。

世界群系与出生

地图包含草地、森林、沙漠和冻原；不同群系有不同的初始温度与食物密度。新玩家优先出生在远离其他玩家的位置，世界拥挤时距离可能缩短。有限感知世界只显示已感知或记忆的区域；不显示的区域不代表空地。

食物与危险

绿色是普通食物，粉色是浆果区的食物（额外 +2 能量），橙色是熔岩（每 tick −5），紫色是尖刺（每 tick −2）。服务器可以选择“围棋生态”规则文件：上下左右相邻的同玩家细胞共同计算气，无气群每轮同时死亡；对角线不能建立连接。单细胞可读取 cell.material_here、cell.biome_here，或从 cell.sense(dx,dy) 读取 material、biome；无法感知时为 None。

三个控制尺度

每份规则任选一个入口。decide_cell 对每个细胞调用；decide_entity 对每个由连接组成的个体调用；decide_unity 对本玩家当前观察到的全部连接个体调用。后两者返回动作列表或 None；每个细胞每轮最多一个动作。

def decide_entity(entity):
    actions = []
    for cell in entity.boundary:
        if cell.food_here > 0 and cell.energy < 20:
            actions.append(cell.eat())
    return actions

entity.cells 是成员细胞，entity.energy 是能量总和，entity.boundary 是边界细胞。连接和断开会改变个体，实体对象每轮重建。

def decide_unity(unity):
    actions = []
    for entity in unity.members:
        for cell in entity.boundary:
            if cell.food_here > 0 and cell.energy < 20:
                actions.append(cell.eat())
    return actions

目前 Unity 是客户端对本玩家全部连接个体的临时视图，不是服务器持久群体，也不是跨玩家连接。不同尺度可以做复杂计算，但都通过细胞提交动作，最终由服务器裁决。

连接自己的本地 ML 算法

  1. 在安装 CellGame 的 Python 环境运行 python -m cellgame.examples.local_agent_service，启动一个本机 HTTP 适配器。示例使用手写规则，本身不是 ML 模型。
  2. 在“code & model”的 model service 输入 http://127.0.0.1:9000/decide，点击启用；连接世界后，每轮客户端 POST 一份观察并等待返回动作。
  3. 编辑示例中的 choose_actions(observation)：把观察转换为模型输入，调用自己的 Python 模型，返回动作列表。模型应事先加载在服务进程中，并在客户端超时前返回。

请求包含 version、tick、cells、neighborhood、env 和 constraints；新感知世界还提供可选的 observation。每个 cell 是 [x,y,type,state,energy]。返回相同 tick、最多每个自有细胞一项动作：

{"tick": 3, "actions": [[1, 2, 1, 2, 3, 0, 0]]}

动作格式为 [源x,源y,目标x,目标y,动作,0,参数]，示例中的 3 是原地进食。空动作使用 []。模型接口需要这个适配协议，普通聊天模型 URL 不能直接使用；只接受本机 HTTP 地址。连接失败或响应超时会显示在运行信息中。服务器决定可以观察的信息和允许的动作；不同感知模式下可见范围不同。

接口与第三方客户端

核心契约为 1.0.0-rc.1，Python 集成从 cellgame.api 导入。查看接口注册表与协议 Schema；完整约定见项目 docs/CORE_STANDARD_zh.md。可选声明 PLAYER_API_VERSION = 1，旧规则省略时仍按版本 1 加载。

组合和代码

展开物种原型与行为组合可修改设置。进阶面板的“当前组合对应的代码”随设置更新，也可以直接修改并预览、启用。修改组合会重新生成代码，之前的编辑可通过“恢复上次编辑”找回；自定义编辑器则独立保存，复制会替换编辑器内容。应用组合与启用代码分别切换当前控制器，预览不修改世界。

玩家本地的程序可以维护更复杂的模型；服务器负责限制与世界交互的范围。高级批量接口和本地模型服务说明见项目的 README.md，完整细胞字段见 docs/automaton_zh.md。

本地预览使用默认世界规则；不同服务器的世界条件可能不同。
